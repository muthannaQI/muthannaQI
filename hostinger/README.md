## 📁 هيكل الملفات

```
public_html/               ← المجلد الجذر على Hostinger
├── index.php              ← التطبيق الرئيسي
├── api.php                ← واجهة PHP للبيانات والمصادقة
├── data.js                ← JavaScript الاتصال بالسيرفر
├── config.php             ← إعدادات قاعدة البيانات ⚠️
├── install.php            ← مُثبِّت قاعدة البيانات (احذفه بعد التثبيت!)

    └── fonts/
        ├── segoeuib.ttf   ← يجب رفعه
        └── consolab.ttf   ← يجب رفعه
```

## 🚀 خطوات الرفع (الترتيب مهم)

### الخطوة 1 — إنشاء قاعدة البيانات

1. افتح **hPanel** → **Databases** → **MySQL Databases**
2. أنشئ قاعدة بيانات جديدة، مثلاً: `u123_bina`
3. أنشئ مستخدم قاعدة البيانات وامنحه **كل الصلاحيات**
4. احتفظ بـ: اسم القاعدة، اسم المستخدم، كلمة المرور

---

### الخطوة 2 — تعديل config.php

افتح الملف وعدّل القيم:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'u123_bina');        // ← اسم القاعدة
define('DB_USER', 'u123_bina_user');   // ← اسم المستخدم
define('DB_PASS', 'كلمة_المرور_هنا'); // ← كلمة المرور
define('APP_SECRET', 'سلسلة_عشوائية_طويلة_32_حرف');
define('APP_URL',  'https://plantaslb.com');
```

---

### الخطوة 3 — رفع الملفات

1. افتح **hPanel** → **File Manager** أو استخدم **FTP (FileZilla)**
2. اذهب إلى مجلد `public_html`
3. ارفع كل الملفات كما هي (حافظ على هيكل المجلدات)

> إذا أردت التطبيق في مجلد فرعي مثل `plantaslb.com/bina`:
> - ارفع في `public_html/bina/`
> - عدّل `APP_URL` في config.php إلى `https://plantaslb.com/bina`

---

### الخطوة 4 — تثبيت قاعدة البيانات

1. افتح المتصفح على: `https://plantaslb.com/install.php`
2. اضغط زر **"تثبيت قاعدة البيانات"**
3. تأكد من ظهور رسالة النجاح ✅
4. **احذف ملف `install.php` فوراً** من File Manager

---

### الخطوة 5 — التحقق

1. افتح `https://plantaslb.com`
2. ستظهر شاشة **"أول مرة؟ أنشئ حساب المدير"**
3. أدخل اسم المستخدم وكلمة المرور للمدير
4. اضغط **دخول** — سيتم إنشاء حساب المدير تلقائياً ✅

---

## 🔒 ملاحظات أمنية

| الإجراء | السبب |
|---------|-------|
| احذف `install.php` بعد التثبيت | يمنح أي شخص إعادة إنشاء الجداول |
| لا تشارك `config.php` | يحتوي على كلمة مرور قاعدة البيانات |
| استخدم HTTPS | Hostinger يوفره مجاناً عبر Let's Encrypt |
| كلمة مرور قوية لـ APP_SECRET | تُستخدم لتأمين الجلسات |

---

## 🆕 تفعيل SSL على Hostinger

1. hPanel → **SSL** → **SSL/TLS**
2. اختر **Let's Encrypt** → فعّل للدومين `plantaslb.com`
3. انتظر دقيقتين ثم تحقق من `https://plantaslb.com`

## ❓ مشاكل شائعة

### "تعذر الاتصال بالخادم"
- تحقق من قيم `config.php` (DB_HOST, DB_NAME, DB_USER, DB_PASS)
- تأكد من أن المستخدم يملك صلاحيات على القاعدة

### "الملف غير صالح" عند الاستيراد
- تأكد أن ملف JSON صادر من نفس التطبيق

### الخطوط لا تظهر
- تأكد من رفع مجلد `design_system/fonts/` بالكامل

### النوافذ المنبثقة لا تفتح عند الطباعة
- اسمح بالنوافذ المنبثقة (Popup) في إعدادات المتصفح لـ `plantaslb.com`
